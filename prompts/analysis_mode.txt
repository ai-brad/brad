Analyze the following JIRA issue.

Your task:
1. Determine whether the requirements are complete and unambiguous.
2. If incomplete, produce a clarification request.
3. If complete but missing test scenarios, propose concrete scenarios.

Output JSON schema:

{
  "requires_clarification": boolean,
  "clarification_text": string | null,
  "has_scenarios": boolean,
  "scenario_text": string | null,
  "implementation_notes": string
}

Rules:
- clarification_text must be actionable and specific.
- scenario_text must be a numbered list suitable for JIRA.
- If requires_clarification is true, has_scenarios must be false.
